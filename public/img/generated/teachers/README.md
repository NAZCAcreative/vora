# Main teacher preview portraits

Generated with the built-in image_gen tool. Fictional AI people; gender assignments are design assumptions, not verified profile attributes. The current 104 profiles reuse twelve models (the four originals plus eight lively portraits). Images are uploaded to the Supabase teacher-portraits bucket, and screens read profiles.avatar_url and profiles.avatar_is_generated from the database. The import-only assignment manifest is supabase/seed/teacher-portraits.json; it is not imported by the frontend. Uploaded teacher photos take precedence. See docs/03-build/teacher-portraits.md for the storage and import workflow.

The eight additional portrait prompts and saved filenames are documented in [lively-portraits.md](./lively-portraits.md).
